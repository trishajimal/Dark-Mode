# Dark Mode Toggle

A small front-end project that demonstrates a light/dark theme switcher using HTML, CSS, and JavaScript.

## Features

- Toggle between dark and light themes
- Respects the user's preferred color scheme on first load
- Saves the selected theme in localStorage so it persists on refresh
- Clean, modern styling with a glass-like toggle button

## Project Structure

- `index.html` — page structure
- `style.css` — theme styles and layout
- `script.js` — theme toggle logic and persistence

## How to Run

1. Open `index.html` in a browser, or
2. Use a local web server such as:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Technologies Used

- HTML
- CSS
- JavaScript

## Notes

This project is a simple example of implementing a theme toggle and storing user preference locally in the browser.
